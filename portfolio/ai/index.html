AI-native

One developer. Many agents.

I lead AI agents the way a tech lead runs a team: every task gets a written brief, a scope and a definition of done. I keep planning, review and Git history for myself.

The pipeline

  1. Plan

    Spec and plan, reviewed before any code.

  2. Brief

    Scope, files, acceptance, checks — one page.

  3. Execute

    A fresh agent, Codex or Claude, picked by risk.

  4. Review

    Diff plus evidence; one fix loop by default.

  5. Ship

    Pull request, green CI, merge.

Guardrails

  • Agents can't push, merge or rewrite history — a hook blocks it.

  • A quota gate refuses launches above 85% of the plan.

  • A second fix loop only for security, data, migration or release work.

  • Every lot ends with evidence: commands, counts, screenshots.
